# BIOS Optimization Guide (AMD & Intel)
> Low-latency configurations for competitive gaming and benchmarking. 

Developed by **scynesthesia**. This repository contains deep BIOS tweaks focused on minimizing input lag and improving frame-time consistency.

## ⚠️ Warning
These optimizations require a **Static Voltage and Static Ratio**. Using these settings without a manual overclock is not recommended. 

**Liability:** I am not responsible for hardware damage or system instability. You are modifying firmware-level settings; proceed with caution.

## 🛡️ Compatibility Notice
For Windows 11 and games with kernel anti-cheats (Valorant, CS2, FaceIT), you **must** keep the following enabled:
* TPM / PTT / fTPM
* Secure Boot
* Virtualization (VT-x / VT-d / SVM)
